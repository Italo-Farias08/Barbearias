# Barbearia
💈 BarberSaaS
Sistema multi-tenant de agendamento para barbearias — cada barbearia tem sua própria página, painel administrativo e link de agendamento.
O que o sistema faz

Agendamento online com seleção de profissional, data e horário
Painel administrativo por barbearia
Controle de profissionais com horários individuais e pausas
Sistema de planos/assinaturas mensais
Controle de gastos e lucro real
Lembretes automáticos via WhatsApp (Baileys)
Comissões por profissional
Multi-tenant — um servidor, várias barbearias
